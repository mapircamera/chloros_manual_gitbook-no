# Utdataformater

### TIFF (16-bit)

16-bit (digitalt pikselverdi 0–65535) Utdata i TIFF (.tif)-format.

### TIFF (32-bit, prosent %)

32-bit (piksel flytende 0,0–1,0) TIFF (.tif) formatutdata. Pikselverdiene representerer refleksjonsprosentene der 0,0 = 0 % og 1,0 = 100 %.

### **JPG (8-bit)**

8-bit (digitalt pikselnummer 0–255) JPG (.jpg)-format.

### **PNG (8-bit)**

8-bit (digitalt pikselnummer 0–255) PNG (.png) formatutdata. Tapsfri komprimering egnet for visning på nettet og visualisering.
